# OneCart – Multi-Store Delivery Platform

## Project Overview

OneCart is a mobile-based multi-store delivery platform that allows customers to browse products from multiple stores, add them to a single shopping cart, and place one combined order.

A single delivery person collects products from all selected stores and delivers them together to the customer.

## Main Features

- User registration and authentication
- Multiple store and product management
- Unified multi-store shopping cart
- Single checkout and combined order management
- Individual store order processing
- Single delivery person assignment
- Order and delivery status management

## Technology Stack

- Mobile Application: React Native
- Backend: Java Spring Boot
- Database: Firebase Cloud Firestore
- Authentication:Firebase Authentication
- Cloud Platform: Microsoft Azure
- Containerization:Docker
- Version Control: Git and GitHub
- CI/CD: GitHub Actions

## Project Status

Currently under development.

## Project Objective

To develop a practical multi-store delivery application while gaining hands-on experience in mobile application development, backend engineering, cloud technologies, containerization, and DevOps practices.
